📌 Problem Example

🔹 Convert to Hexadecimal

Difficulty: Easy

Problem Statement:
Given an integer "a", print its hexadecimal representation.

---

💡 Approach

- Use built-in conversion ("hex" in C++ / Python)
- Or manually convert using division by 16

---

✅ Sample Input

26

✅ Sample Output

1a

---

💻 Solution (C++)

#include <iostream>
using namespace std;

int main() {
    int a;
    cin >> a;

    cout << hex << a << endl;

    return 0;
}
